## 1. Project Overview

As part of my cybersecurity practical training with NetworkWalks, I completed a password-cracking exercise using the NetworkWalks password-cracking tool and John the Ripper.

The exercise provided hands-on experience in cracking passwords and hashes, demonstrating how weak or predictable passwords can be vulnerable to password-cracking attempts.

## 2. Objectives

- Understand how password cracking works.
- Gain practical experience using password-cracking tools.
- Learn how password hashes can be tested for weaknesses.
- Understand the security risks associated with weak passwords.

## 6. Key Lessons Learned

- Simple and predictable passwords are easier to guess or crack.
- Common passwords are particularly vulnerable to dictionary attacks.
- Password length and complexity contribute to password strength.
- Reusing passwords across multiple platforms increases security risks.

## 7. Security Recommendations

1. Create long, unique passwords for every account.
2. Use uppercase and lowercase letters, numbers and special characters.
3. Avoid personal information, common words and predictable patterns.
4. Use a reputable password manager.
5. Enable Multi-Factor Authentication (MFA).
6. Never reuse passwords across different accounts.

## 8. Conclusion

This practical exercise strengthened my understanding of password security and provided hands-on experience with two password-cracking tools: NetworkWalks and John the Ripper.

It reinforced the importance of strong authentication practices and the need for individuals and organisations to protect their accounts against password-based attacks.
